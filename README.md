# EspBox

## 使用

### 烧录镜像

在release中下载最新版的镜像，解压后使用esptool烧录：
```
python -m esptool --chip esp32 -p {串口设备名} --baud 460800 write_flash --erase-all 0x0 espbox_v1.bin
```

### 切换应用

EspBox通过连续复位（或开关机）来切换应用。开机白屏后会显示花屏或上次关机前的最后一帧画面，此时在进入实际引用画面（比如模拟器LOGO）之前，立即复位或关机，再次启动时会顺次切换到下一应用。

初始应用只有文件管理服务器，该应用运行时屏幕呈纯土黄色，不能操作。在文件管理服务器状态下关机，下次开机默认会切换到下一应用（如果有）。

### 管理文件

在文件管理服务器下（屏幕纯土黄色），可用手机等任意WIFI设备连接EspBox的WIFI热点，名字是espbox-ap，没有密码。在连上热点后，通过浏览器打开192.168.4.1即可进入文件管理页面。
在其中可以进行文件的上传下载和删除。上传文件最大支持单个2M。

### 命名应用

目前EspBox仅支持gameboy模拟器gnuboy。在上述文件管理页面根文件夹下，将单个rom文件压缩为名字是\*.gbc.zip的压缩文件，上传入EspBox后，即可通过切换应用启动该rom。

### 扩展按键菜单

在gnuboy模拟器运行状态下，长按预设的触发键，即可暂停应用在屏幕右上角打开扩展按键菜单。
此时按下触发键相对的那个键（比如A键触发就是B键），则可以关闭菜单恢复应用运行。

- 菜单第一排3个从左到右依次是：选择键，开始键，预设触发键。选到任意键上后按住触发键，应用将立即恢复运行，并且是做按住的是选中的按键，直到松开触发键。
- 菜单第二排3个从左到右依次是：复位模拟器，即时读档，即时存档。选中后按下触发键确定。

### 配置菜单触发

可以通过rom文件名称配置菜单的触发方式。rom文件名后的第一个"."后的字段即为配置文字。
比如文件名`rom_name.a3e.gbc.zip`中的`a3e`即为配置字段（区分大小写）。如果没有配置字段，则使用默认配置。

- 第1个字符为a或b，表示使用A键还是B键作为触发键。默认为B键。
- 紧接着为一串数字，表示按住触发键多少时间触发菜单。每1点代表逻辑30帧，理论上应该是半秒，实际因为无法满帧而略微长一些。默认为60帧。
- 最后一个字符可选为e或者留空，为e时代表触发键正常作为A键或B键功能使用；留空时代表触发键按下时不作为功能键，但未触发就松开时立即视为轻点一次对应A键或B键功能键。默认为留空。

### 存档文件

gnuboy的存档文件为同名.sav文件，即时存档文件为同名.sta文件（仅支持一个）。可通过文件管理页面导入导出。
